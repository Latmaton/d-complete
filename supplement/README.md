# Complete parameter supplement

The sole parameter source is `parameters.py` in the program root. This directory is generated by `python export_parameters.py`. The verification program reads `parameters.py`, not the exported tables in this directory or height distributions, terminal counts, or density results from previous runs.

There are 8 base pairs, 71 period positions, 191 scales, 466 contiguous intervals, and 2426 interval choices. The case pages and CSV files below list everything, including every endpoint and every `(i,k)`.

## Format and consistency checks

Integers are written in decimal notation, and rational values as reduced fractions `numerator/denominator`. Values are never converted to floating point, and fractions are not replaced by decimal approximations. CSV files use UTF-8 encoding and comma separators. Import columns containing large integers or fractions as text in editors or spreadsheet software to prevent automatic conversion to approximate decimals.

Run `python export_parameters.py --check` from the program root to check every exported file against the current parameter source character for character. This checks parameter transcription only; it does not establish that residue, terminal, or density verification has passed. For the role of each parameter and where it is checked, see the [parameter documentation](../docs/01_parameters.md).
